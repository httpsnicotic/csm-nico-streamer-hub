SEGURIDAD
---------
GitHub Pages no puede esconder el código HTML/CSS/JS del navegador.
Eso NO debe ser la barrera de seguridad.
La barrera real de escritura es Supabase Auth + RLS + public.admins.

En producción, si Supabase NO está configurado, la V5.8.4 bloquea el editor de admin.html automáticamente.
En localhost, file:// y redes LAN privadas se permite MODO LOCAL para seguir diseñando.
